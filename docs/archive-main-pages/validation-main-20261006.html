Result 3 — the gate decision, honestly

  • Graded DS belief (F) vs parents, blocked off-catalogue: F does not beat either parent in the 4 quadrants (0/4). Under the literal gate, the graded belief file alone would not earn the slot.
  • DS support at full confidence (D) vs parents, pooled off-catalogue: 0.0960 vs 0.0940 (A) and 0.0942 (B) — the union of the two families is the best-supported emission we can build from them. This is the shipped primary.
  • Intersection-only (E/G): worst arm (0.0806). Over-pruning confirmed: β=0.8 punishes dropping truth that either family sees.
  • Catalogue proxy: ranks B ≈ D > F ≫ A (A scores 0.0067). This ordering is known to be anti-predictive for this playbook — A scored 0.2778 live while ranking last here — so the catalogue proxy is reported, never used for selection.

Limits of this validation (flagged, not hidden)

  • Both truth sets are proxies. The hidden set is expert-mapped faults deliberately absent from every public compilation; SGMC off-catalogue cells resemble that population but are not it. Proxy DTI values (≈0.09) are not comparable in magnitude to live scores (≈0.26–0.28); only within-proxy orderings are evidence.
  • Pooled deltas of ≈0.002 sit inside the noise band of the sibling programs' Monte-Carlo instruments (±0.003–0.005). The tier-sweep monotonicity and the intersection collapse (−0.013) are well outside it; the parent-vs-union margin is a directional, not a certified, statement.
  • No organizer score exists for anything on this site until the file is submitted.
