Withdrawn: the former 0.2 × DTI values (including about 0.052) were presented as universal live break-even bars. That interpretation is not generally justified and must not be used as a candidate gate.

Official metric

k(d) = max(1 − d/R, 0)
TPw  = Σ_g max_x p(x) k(d(x,g))
FPw  = Σ_x p(x) [1 − max_g k(d(x,g))]
FNw  = Σ_g [1 − max_x p(x) k(d(x,g))]
DTI  = TPw / (TPw + 0.2 FPw + 0.8 FNw + ε)

Truth-centred TPw and prediction-centred FPw are not generally complements. In particular, FPw=S−TPw (or an equivalent assumption that prediction-centred credit equals truth-centred TPw) is not a general identity. A threshold such as 0.2 × DTI is only a local conditional result in restricted one-variable geometry; it is not a universal per-dot threshold, hidden-truth calibration, or removal budget.

See the repository's metric-identity erratum and current metric page.

Dempster–Shafer interpretation

  • m(Θ) is ignorance / unassigned mass.
  • K is raw conjunctive conflict assigned to the empty set before normalization.
  • Normalized Dempster combination divides non-empty masses by 1−K; it does not transfer K to m(Θ). A Yager combination instead transfers K into Θ, so a Yager unassigned output can include both ignorance and conflict.

Do not conflate an ignorance layer with a separate raw-conflict layer. Neither is automatically calibrated probability or performance evidence. The H50 pages preserve the normalized-Dempster distinction, but all reliability discounts remain historical assumptions.
