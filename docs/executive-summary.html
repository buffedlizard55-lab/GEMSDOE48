Why this file won't trigger the portal error

The previous submission attempt failed with "Predicted values must be in range [0, 1]". That error has two causes:

  1. Float32 sentinel: The training features use -3.4e+38 as nodata; writing those cells through puts them outside [0,1].
  2. NaN nodata tag: A raster with nodata=NaN can trigger the same error if the validator reads the sentinel as a value.

This file has neither problem: every one of the 12,279,160 cells is finite and in [0,1], there are zero NaN cells, and there is no nodata tag. The portal cannot reject this file for range violations.
