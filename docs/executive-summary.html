Step-by-step submission instructions

  1. Download the TIF with the green button above (or the .zip, which contains the same single GeoTIFF).
  2. Open the competition page and log in: drivendata.org/competitions/306/competition-doe-gems (rules/overview: page 967, data: data tab).
  3. Click "New submission" on the leaderboard/submission panel.
  4. Choose the file under "File to submit" — the single-band GeoTIFF (or the zip containing one GeoTIFF).
  5. Paste the unique name and note into the "Note (optional)" field:
    GEMSDOE48-H59-CoverDSBelief-B2xH33D | GEMSDOE48 H59 | Dempster Bel(F), dotted B2 x tip H33D; 400m hex-cover of the fusion corridor; m(Theta) layer
  6. Click "Create". Promotion to a real weekly slot is a separate selection step inside the weekly cap shown on the submission page — this page documents the artifact, it does not spend a slot by itself.
