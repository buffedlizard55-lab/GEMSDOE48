Scientific correction: classical normalized Dempster's rule divides by 1−K, thereby normalizing conflict away. The brief asks to retain disagreement. This implementation therefore uses Yager's published modified Dempster rule, which transfers conflict K to the unassigned frame Θ. Calling that behavior “classical Dempster's rule” would be inaccurate.

Why 0.2778 likely worked—and can this beat it?

The official DTI penalizes false-positive mass by 0.2 but false-negative mass by 0.8 and gives distance credit only inside 300 m. Sparse dot spacing can retain near-fault coverage while deleting redundant mass, increasing credit density. The H33-2-B2 artifact also removes near-catalogue flank cells, leaving a compact 37,654-cell field. This mechanism is consistent with the metric and the family's score progression, but hidden labels prevent a causal proof.

This fusion can beat 0.2778 only if tip-only cells recover enough hidden truth to offset their added mass and if downweighted dotted-only cells are mostly false positives. The proxy supports that hypothesis, not the stronger claim. The official leaderboard observed on 2026-10-06 is led by 0.3774, so the brief's “0.3195 highest” statement is stale. No honest analysis can promise >0.3774 before organizer scoring.
