Metric implementation and historical correction

The exact weighted DTI implementation and tests are documented in the metric module and its test suite. For the official metric's sufficient statistics, TPw=T, FPw=S−Q and FNw=N−T; the maxima T and Q use different axes. Therefore FPw=S−TPw is not a general identity.
