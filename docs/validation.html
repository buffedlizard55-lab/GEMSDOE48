Metric implementation and historical correction

The exact weighted DTI implementation and tests are documented in the metric module and its test suite. For the official metric's sufficient statistics, TPw=T, FPw=S−Q and FNw=N−T; the maxima T and Q use different axes. Therefore FPw=S−TPw is not a general identity. H55/H56/H57-RELIEF live-score projections, the 0.2843 claimed ceiling, H56B's 0.0649 and H57-RELIEF's 0.3844 projections, inferred hidden-positive counts, and universal 0.0556/0.0549-per-dot claims are invalid as scores/gates.
