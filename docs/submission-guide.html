If the portal says “Predicted values must be in range [0, 1]”

This primary file cannot produce that error. All 12,279,160 cells are finite, the whole-raster minimum is 0.0 and the maximum is 1.0, and nodata is unset. The audit asserts portal_range_error_immune: true on the re-read bytes, not on an in-memory array.

The cause of that rejection is almost always a NaN cell. Any NaN makes a vectorised np.all((v >= 0) & (v <= 1)) test return False, because every comparison against NaN is false — which reproduces the message exactly. Two encodings circulate in this project and both have owner-reported live scores:
