Why two files?

The belief file is the graded evidential surface (Shafer 1976): where the fused evidence commits, where it abstains. The decision file (primary) is what the spatially-blocked off-catalogue holdout selected for submission: the DS support (combined belief > 0) emitted at full confidence, because the tier sweep measured full confidence as optimal (see validation). Same evidence, two representations — submit the decision file.

Can this beat 0.2778 / 0.3195? — the honest answer

Upside case: the metric is a budget — each emitted pixel must clear the credit bar ≈ 0.2·DTI ≈ 0.055. The 0.2778 base cleared it with 37,654 dots; this submission adds 10,251 disagreement dots that the best available off-catalogue truth proxy rates net-positive (+0.0020 pooled DTI over the better parent). If the hidden expert-mapped faults reward the union as the SGMC proxy does, the score should improve over the parents; the Final Prize Round additionally re-scores against an expanded label set built from expert review of submissions — disagreement dots are precisely candidate new faults, corroborated by one of the two strongest independent families.

Downside case: if the hidden set penalizes the extra 10,251 dots more than the proxy does, the score lands at or below the 0.2778 parent. Expected value is positive on the only instrument that has ever ranked these families correctly (the catalogue proxy is known to be anti-predictive for this playbook — dotted scored 0.2778 live while ranking last on catalogue truth).

Closing the gap to 0.3195+ requires more credit density — better detectors, not better budgeting. The ranked research agenda for that is on the next-hypotheses page.
