Dempster–Shafer combination

Two geological evidence families, normalized belief as a relative favorability surface, and separate uncertainty/conflict diagnostics.

Inputs are distinct evidence families

The two parent surfaces are a dotted-family B2 mask and an H33-D tip/step-over mask. Each was converted to a 300 m triangular maximum-credit support field using the official DTI distance kernel. Their masks share 31,614 cells (out of 37,654 dotted and 41,865 tip cells), so statistical independence is not established. This is a combination of two related/overlapping sources, not two independent confirmations.

H56B: graded belief recipe

Fixed reliabilities: dotted r=0.95; tip r=0.95×0.2632/0.2778. The two numbers are owner-reported parent leaderboard figures used as recipe constants, not organizer-verified scores for the exact local bytes. Absence information varies by the H19-5 backbone and, for dotted evidence only, a 200 m catalogue flank; that rule is an assumption, not verified local file attribution.

For support sᵢ(x) and absence informativeness aᵢ(x):

mᵢ(F)=rᵢsᵢ
mᵢ(¬F)=rᵢ(1−sᵢ)aᵢ
mᵢ(Θ)=1−mᵢ(F)−mᵢ(¬F)

H56 open-world D-S: separate recipe

Uses the same pinned family pair with discounted open-world BPAs: reliability α=0.60 per parent and absence informativeness 0.10. It does not use H56B's owner-reported-score-scaled reliability or its backbone/catalogue-conditioned absence settings. It is a different parameterization of family fusion, not a new geology hypothesis.

Its recipe and file identity are recorded in the H56 results report and the build receipt.

Normalized Dempster rule and mass terms

For two sources over frame {F, ¬F}, with Θ as uncommitted mass, the unnormalized conflict is:

K = m₁(F)m₂(¬F) + m₁(¬F)m₂(F)

Normalized Dempster combination divides non-conflicting intersections by 1−K. For example, m₁₂(F)=[m₁(F)m₂(F)+m₁(F)m₂(Θ)+m₁(Θ)m₂(F)]/(1−K); m₁₂(Θ)=m₁(Θ)m₂(Θ)/(1−K), with the corresponding expression for ¬F. Code uses a bounded denominator for numeric safety and checks that masses sum to one across the footprint.

  • Bel(F): combined mass committed to fault-supporting singleton F.
  • m(Θ): unassigned / ignorance mass. It is not conflict and does not directly map “where sources disagree.”
  • K: raw, pre-normalization conflict mass.
  • Pl(F)=Bel(F)+m(Θ): plausibility of F, exported separately.
  • H56-OWDS support difference: absolute difference between its two pre-combination support fields; this is a direct disagreement diagnostic, not a D-S mass.

For H56B, the primary is raw Bel(F) divided by its maximum within the valid footprint, written on the footprint and zero outside. This normalizes to [0,1] but removes absolute mass scale. It is a relative ranking/favorability surface, not a calibrated probability of fault or a validation score. Diagnostic mass TIFFs are not submission candidates.

Validation result and limitations

H56B: 0.032347 catalogue / 0.070552 SGMC off-catalogue, versus H49 0.095353 / 0.100751; 0/4 folds above H49 for either proxy. H56-OWDS: 0.054242 / 0.066070; also 0/4 folds above. Proxies use public map products, not private competition labels. Fixed upstream sources were not refit inside each fold, making results conditional and potentially leaky.

The parent sources' provenance is owner-mirrored, and their 0.2778/0.2632 report-to-local-file association remains unverified. The exact B2 file is marked UNSCORED. H56B's primary zeros-outside TIFF passes local core format checks but differs from the problem page's null/NaN outside wording; the NaN-outside twin is available, and neither is portal-accepted. See H56B erratum, validation record, and submission status.
