Conflict-preserving evidence fusion

For a binary frame Θ={fault F, not-fault N}, the current implementation discounts each parent confidence x by reliability r:

m(F) = r x
m(N) = r (1 − x)
m(Θ) = 1 − r

The conjunctive product gives:

m₁₂(F) = m₁(F)m₂(F) + m₁(F)m₂(Θ) + m₁(Θ)m₂(F)
m₁₂(N) = m₁(N)m₂(N) + m₁(N)m₂(Θ) + m₁(Θ)m₂(N)
K      = m₁(F)m₂(N) + m₁(N)m₂(F)
Yager: m₁₂(Θ) = m₁(Θ)m₂(Θ) + K

The unassigned diagnostic stores Yager’s m(Θ). Scientific terminology matters: classical normalized Dempster combination divides non-empty masses by 1−K and removes the conflict from the normalized result. Yager’s modified Dempster rule transfers K to Θ. Sentz & Ferson (2002) describe both variants.

Reliability discounts 0.90 (dotted) and 0.85 (tip) were fixed before the original proxy evaluation; they are heuristic family-level values, not calibrated probabilities. Crucially, this transform interprets a zero in a sparse detector raster as evidence for N. That may be wrong: a zero may simply mean “this detector did not emit a candidate,” i.e. ignorance. The corrected proxy loss makes this semantic assumption a primary reason not to submit. Any redesigned evidence assignment must state whether a silent detector contributes negative evidence or unassigned mass and validate that design without reusing a submission slot.

Correct organizer metric implementation

The organizer’s published metric uses α=0.2, β=0.8 and a 300 m triangular kernel, k(d)=max(1−d/300 m,0). For each truth pixel, the true-positive term is the maximum nearby prediction confidence times kernel weight, not just whether any positive cell is nearby:

TPw = Σg maxx [ p(x) k(d(x,g)) ]
FPw = Σx p(x) [ 1 − maxg k(d(x,g)) ]
FNw = Σg [ 1 − maxx (p(x) k(d(x,g))) ]
DTI = TPw / (TPw + 0.2 FPw + 0.8 FNw)

src/gems48/validation.py implements these terms using local weighted maxima and full-scene Euclidean distances. The spatial proxy partitions TP/FP/FN contributions into four quadrants but computes neighborhoods on the full raster, avoiding artificial truncation at block borders. Exact known-catalogue fault pixels (labels=1) are excluded following the DrivenData staff clarification. SGMC proxy targets within 300 m of known faults are excluded only as a conservative proxy-truth construction choice.

Validation correction and retraction

The inherited v1 proxy score was invalid for fractional predictions. It replaced the fusion values with a positive-support mask when calculating TP (distance_transform_edt(pred <= 0) followed by the distance kernel), omitting the required p(x) factor. It also cropped each quadrant before computing distance transforms. That falsely made the v1 fusion appear to beat the dotted parent in all four folds. The v1 result and gate pass have been explicitly retracted.

Artifact audit and known format conflict

  • The primary hash is fe68ae6f57be013e26d20006551b43cd84bb5fe4a0b07d1d10ce4725c90fd16c. It is single-band float32, EPSG:32611, 100 m, 3730×3292, and every value is finite in [0,1].
  • The official problem description says outside-bounds cells should be null/NaN. This candidate writes finite zero outside because the owner encountered a portal “[0,1]” error and NaN fails a naïve range comparison. This is an explicit documented deviation; portal acceptance is not verified.
  • A historical-artifact scan retrieved and blob-hash-verified 336 unique TIFF blobs listed by the owner’s 2026-10-06 inventory. 334 matched the exact prediction grid; two did not. There were no exact raster-value or positive-support-mask matches. The closest positive-support Jaccard was 0.87392 (the tip parent). This bounded owner-repository scan is not global uniqueness proof.
  • The Pearson correlation with the naïve mean is 0.96359, which is high because the parents share 31,614 positive cells. Non-averaging is established by exact comparison: 16,291 cells differ; max absolute difference is 0.41371; pixel equality is false. Correlation alone would not establish non-equivalence.
  • The separate unassigned-belief GeoTIFF is diagnostic only. Do not submit it.

Limitations and next decisions

  1. No DrivenData account/session is available; no submission was uploaded, no private score observed, and no portal acceptance verified.
  2. The parent scores and exact parent-to-leaderboard attribution are owner-reported; public leaderboard rows do not publish TIFF hashes.

  4. The two parents overlap heavily (31,614 common positives) and are not demonstrably independent. Dempster–Shafer combination assumptions are therefore weak.
  5. The next geological candidate requires gravity/magnetic feature grids not present in this checkout.
