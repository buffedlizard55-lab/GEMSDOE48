H-A · Lateral lineament coherence as a pruning signal — FALSIFIED, measured

Layers: the incumbent emission's own support field (no external data needed). Signature: structure-tensor coherence (λ₁−λ₂)/(λ₁+λ₂) of the kernel-support field at σ = 2 and 4 cells, local dot density at r = 3/5/8 cells, connected-component size, distance to the public catalogue, and local support sum.

Why it should work: a fault is a laterally persistent structure that produces a collinear scarp, drainage offset, magnetic contact and strain-rate anomaly over kilometres, whereas ridge-detector noise (alluvial-fan edges, ploughed-field boundaries, roads, canal banks, DEM tile seams) is isolated, blobby or short. If coherence predicted credit, the low-coherence tail could be pruned and the freed mass re-spent.

Result [MEASURED]: it does not. Every quintile of every feature carries the same realised proxy credit per cell — coherence σ2: 0.155 / 0.143 / 0.150 / 0.140 / 0.160; coherence σ4: 0.158 / 0.155 / 0.147 / 0.143 / 0.146; density r5: 0.168 / 0.153 / 0.156 / 0.139 / 0.140; distance-to-catalogue: 0.163 / 0.147 / 0.159 / 0.154 / 0.127 — all far above the removal threshold of 0.037 proxy credit per cell. Full receipt. The incumbent's cells are homogeneous with respect to every geometric feature computable from the emissions alone, which means no further pruning can be justified without new data. This negative result is the single most useful measurement of the session: it closes the pruning lane.

How each differs from what this repository already does

  • H-A is new to this repository and was tested here (falsified). It used only the emissions themselves — no external data.
  • H-1 … H-5 all require data this repository has never loaded. The current pipeline fuses two existing emissions; it has never built a detector from raw geophysical, thermal or seismic layers, and it has never applied a geothermal prior. Every one of them produces a new candidate surface that could enter a future fusion as a third evidence source.

Gate before any submission slot

Per the standing brief, a candidate is only slot-eligible after it beats the current holdout best under the frozen protocol: 16 spatial blocks, SGMC off-catalogue truth, official metric, with the improvement positive in the block mean and in a majority of blocks, and with the marginal credit of any added mass above the live acceptance bar α·DTI ≈ 0.056 converted into proxy units. Given H-A's falsification and the measured local optimality of the incumbent emission, the honest expectation is that only a hypothesis that brings new information (H-1, H-2, H-3) can clear that gate — re-cutting the existing families cannot.
