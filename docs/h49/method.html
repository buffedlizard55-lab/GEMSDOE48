0 · The metric, implemented literally

From the official problem description:

k(d)  = max(1 - d/R, 0)                                   R = 300 m = 3 cells
TP_w  = Σ_{g∈G}      max_{x: d(x,g) ≤ R}  p(x)·k(d(x,g))
FP_w  = Σ_{x: p(x)>0} p(x)·[1 - max_{g∈G} k(d(x,g))]
FN_w  = Σ_{g∈G}      [1 - max_{x: d(x,g) ≤ R} p(x)·k(d(x,g))]
DTI   = TP_w / (TP_w + 0.2·FP_w + 0.8·FN_w)

src/gems48/metric.py implements exactly that, and tests/test_metric.py checks it cell-for-cell against a brute-force loop transcription on random fields. Three properties matter for everything below and are asserted in tests:

  • TP takes a MAX over the kernel support, weighted by p — not “nearest positive cell”, and not a binary indicator. This is where the previous session's proxy approximation was wrong: it discarded the magnitude of p in TP, so it could not see that halving a value halves the credit.
  • TP + FN = |G| exactly, so the metric collapses to 1/DTI = α + α·(F/T) + β·(K/T).
  • Scaling every prediction by λ gives 1/DTI(λp) = α + α(F/T) + (β/λ)(K/T) — the identity used to invert live scores into T and K.

The published worked example (TP = 3.00, FP = 1.89, FN = 2.00 → 0.60) cannot be reproduced pixel-for-pixel because the page does not publish the pixel values behind its figure; the test asserts the arithmetic, and flags this as an unreproducible figure rather than claiming verification.

2 · Evidence fields

Both parents are sparse binary emissions, which cannot be compared cell-by-cell (their cells rarely coincide). Each is therefore converted into a graded field using the competition's own kernel:

s(x) = max over the family's cells y of k(d(x, y))        s ∈ [0,1]

s(x) reads as “the credit this cell would realise if a truth pixel sat on it” — the natural currency of the published metric. It also carries each family's positional uncertainty, which is what lets the combination disagree in position rather than only in presence.

3 · Masses, combination, and why Yager

Frame Θ = {F, N}. Each source is discounted by reliability (Shafer's discounting of a categorical opinion):

m_s(F) = r_s·s_s        m_s(N) = r_s·(1 - s_s)        m_s(Θ) = 1 - r_s

Reliabilities are preregistered: r_dotted = 0.90 for the stronger parent and r_tip = 0.90 × 0.8915 = 0.802, where 0.8915 is the ratio of the two parents' measured live credit-per-dot efficiencies (0.1199 / 0.1345) from the live-anchor inversion. Conjunctive combination then gives

m(F)   = a_F b_F + a_F b_Θ + a_Θ b_F
m(N)   = a_N b_N + a_N b_Θ + a_Θ b_N
m(Θ)   = a_Θ b_Θ
K      = a_F b_N + a_N b_F          (empty-set mass = conflict)
Scientific correction, retained from the previous session and re-verified here. Classical normalised Dempster's rule divides the non-empty masses by 1 − K, which deletes the conflict: two sources that flatly contradict each other still return a crisp answer. Because the deliverable must keep the disagreement visible, the combination uses Yager's modified Dempster rule, which transfers K to m(Θ). For a binary frame Yager's rule and the Dubois–Pradé disjunctive rule coincide. The classical rule is still computed and published, so the difference is shown rather than asserted: at total contradiction with r = 0.9, Dempster returns 0.474/0.474 with a 0.053 residue on Θ, while Yager returns 0.178/0.080 with 0.742 unassigned. Mass conservation error: 2.2 × 10⁻¹⁶.

Decision score: the pignistic probability BetP(F) = Bel(F) + m(Θ)/2 (Smets' betting transform), the standard way to turn a belief function into a single number for action.

4 · Emission: mass-budgeted and spatially balanced

Two facts set the design:

  • p = 1 is optimal on the admitted support. Both credit (p·k) and cost (α·p) are linear in p, so the decision to admit a cell is independent of p; given admission, credit is capped at 1 per truth pixel, so a lower p only throws credit away. This is why the graded “belief-as-value” emission of the previous session loses: it halves the value of exactly the cells that carry the credit.
  • Coverage beats peak score. The metric takes the MAX over the kernel support, so two cells 1 cell apart on the same structure compete for the same truth pixels. A plain “top-N by belief” emission clusters and loses; the live record agrees (Poisson-disk spacing d = 2.8 px beat d = 1.5 px).

The emission therefore walks cells in descending pignistic order and admits one only if no already-admitted cell lies within 2.5 cells, until the budget is reached. The budget is 47,905 = |dotted ∪ tip|: the smallest budget at which both families are fully represented, which is the point of a two-family fusion.

Result [MEASURED]: 31,614 agreement cells + 6,040 dotted-only + 3,842 tip-only + 6,409 fused compromise cells; Jaccard 0.786 with the dotted parent.

8 · Limitations

  • No DrivenData session: the agent cannot spend a slot, and portal acceptance is unverified by us.
  • The SGMC proxy is not the hidden expert label set and is 5.7× denser, which biases it toward adding mass; all addition decisions are therefore taken against the live bar converted into proxy units, never against the proxy's own bar.
  • The two parents are 84 % co-located, so “independent evidence sources” is an approximation; the combination is therefore conservative (no source is given more weight than its measured efficiency justifies).
  • Live anchors are owner-reported; no organiser receipt ties 0.2778 or 0.2632 to specific bytes.
  • The proxy mis-orders the two parents. Both proxy protocols place the tip family ~0.001 proxy DTI above the dotted family, while the live board has the dotted family ahead by 0.0146. Proxy gaps below roughly 0.005 therefore carry no information; that is why the submission decision rests on the live-anchored calibration of section 5 and not on the proxy ranking.
  • The 419 MB official feature stack and every external geothermal/seismic source are unreachable from this sandbox, so no new detector could be built or validated here.
