Historical inversion and score-calibration method withdrawn. The official metric is not invertible from the owner-reported score/mass pairs using the former FPw=S−TPw substitution.

Official metric components

With kernel k(d)=max(1−d/R,0), the public metric is implemented as:

TPw = Σ_g max_x p(x) k(d(x,g))
FPw = Σ_x p(x) [1 − max_g k(d(x,g))]
FNw = Σ_g [1 − max_x p(x) k(d(x,g))]
DTI = TPw / (TPw + 0.2 FPw + 0.8 FNw + ε)

TPw aggregates truth-centred maxima; FPw aggregates prediction-centred residual mass. They are generally not complements. In particular, FPw = S−TPw is not a general official-metric identity. The old nested-ladder inversion therefore does not identify a private truth count, weighted TP, recall, score ceiling, or threshold.

The maintained implementation and erratum are linked at metric-identity erratum; code-level tests compare the exact metric implementation with a brute-force oracle.

Dempster–Shafer: ignorance and conflict

  • m(Θ) is ignorance/unassigned mass over the frame Θ.
  • K is conflict, mass assigned to the empty set under the unnormalised conjunctive combination.
  • Under Yager's rule, K is transferred into Θ; the resulting unassigned mass includes both prior ignorance and transferred conflict.

Therefore an output labelled m(Θ)+K is a combined Yager-unassigned layer, not the raw, separate conflict raster. The H49 unassigned diagnostic must not be cited as a K-only map. The historical r_tip=0.802 reliability value was derived from the invalid live inversion and is withdrawn as a performance calibration.

What remains reproducible

Local file hashes, grid and format checks, the deterministic DS computations, and public-proxy scores can be reproduced as historical diagnostics. None establishes organizer acceptance or private-label performance. The H49 parent decomposition JSON is preserved with explicit invalidation status at docs/data/h49-parent-decomposition.json.

Historical H49 command: the former scripts/analyze_parents.py can no longer overwrite active documentation. It requires --legacy-audit-only and writes to evidence/forensic/ by default.

Numerical reproducibility does not validate assumptions or turn owner-reported scores into organizer evidence.
