Why the historical 0.2778 is plausible—and what is not proven

The official distance-weighted Tversky index uses α=0.2 for false positives and β=0.8 for false negatives, with a 300 m triangular tolerance. A sparse, spaced fault proposal can gain credit density by removing redundant off-target mass while preserving near-trace recall. That is a mechanistic explanation consistent with the metric, not a causal proof of why a particular upload scored 0.2778. Owner-reported artifact/score attribution is not tied to a public TIFF hash.

The public leaderboard snapshot observed 2026-10-06 has a leader at 0.3774; 0.3195 is rank 7 in that snapshot, so it is not the current top score. Public scores can change. This project makes no promise that the candidate—or any next method—will exceed 0.2778 or 0.3774.
