## The metric does not identify hidden truth mass from a score alone

For prediction values `p(x)`, truth locations `g`, and the official triangular kernel `k(d)=max(1-d/300m,0)`, define

```text
S    = sum_x p(x)
T    = sum_g max_x p(x) k(d(x,g))       # truth-centred weighted TP
Q    = sum_x p(x) max_g k(d(x,g))       # prediction-centred credit
N    = number of truth locations
TPw  = T
FPw  = S - Q
FNw  = N - T
DTI  = T / (0.2*T + 0.2*S - 0.2*Q + 0.8*N + epsilon)
```

`T` and `Q` maximize over different axes and are generally unequal. Therefore `FPw = S - TPw` is not a general identity. A leaderboard DTI and a prediction count do not determine a unique hidden-truth count, hit rate, recall, or marginal value for an added dot. The old spreadsheet/script inversions using that substitution, including the putative 0.2843 “ceiling”, estimated `|G|`, fixed-mass target table, and universal 0.0556-per-dot bar, are invalid as exact metric inferences. Their historical outputs are retained for audit only; see the [metric-identity erratum](metric-identity-erratum-20261007.md) and [`evidence/live_ladder_20261007.json`](../../evidence/live_ladder_20261007.json).

## A cautious explanation of the reported ladder

The owner's description reports successive changes in a dotted family and associates its last rung with a catalogue-pruned B2 raster. The official mask clarifies that only exact training-label pixels are excluded; it does not make the surrounding 200–300 m band free of false-positive penalty. Pruning can change spatial coverage, prediction mass, and proximity to the unknown new-fault labels, so a score effect is possible in either direction, but no direction or mechanism follows from the mask rule alone. The exact rung masks, scores, scorer version, data split, and file bytes have not been linked by an organizer receipt. The algebraic consistency of the old inversion cannot establish the mechanism because that inversion used the invalid identity above.

Thus the appropriate conclusion is narrower: **the reported 0.2600→0.2708→0.2778 ladder and the 0.2778 leaderboard row have no verified causal explanation in this checkout.** Catalogue-flank pruning is part of the owner-reported file history, not a verified score mechanism. The public 0.2778 row belongs to `extradr19`; it is not evidence that this repository's B2 TIFF earned that value. See the 2026-10-08 [mask/leaderboard correction](leaderboard-and-mask-clarification-20261008.md).
