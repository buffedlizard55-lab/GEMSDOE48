## 2. H51 — plausibility-budget emission (new unique construction)

H50 showed the normalized Dempster **belief** is intersection-like and loses
to both parents and the union on the blocked proxies, and that the official
DTI = TPw/(TPw + 0.2·FPw + 0.8·FNw) makes binary {0,1} emission on a fixed
support optimal. H51 keeps the exact H50 fusion (same parents, reliabilities,
rule) and changes only the decision layer: **emit binary 1 on the top-B cells
ranked by plausibility Pl(F) = Bel(F) + m(Θ)**, the upper Dempster–Shafer
interval bound (Shafer 1976, §2.1), with B = 37,654 mass-matched to the
dotted parent. Ranking by Pl is the optimistic/interval-dominance rule:
commit wherever the combined evidence has not positively refuted a fault.
It is distinct from H49 (Yager + pignistic midpoint, different parents,
spacing-thinned, 47,905 budget) and from every prior artifact (no Pl-ranked
emission exists anywhere in this repo or the reviewed sibling pages).

Preregistered before scoring: budget 37,654; reliabilities 0.95 / 0.926746;
deterministic lexsort tie-break. Artifact
`gemsdoe48-h51-plausibility-budget-20261007-f8fa1d08-zeros.tif`
(SHA-256 `f8fa1d0817712d34935acd70663eb14c510876598c4f70729fcd79288706120f`).

Structural facts observed at build time:

- every emitted cell lies inside the parents' committed-pixel union:
  H51 is a **budget-trimmed union** (37,654 of 49,066 union cells; Jaccard
  0.7674) dropping the lowest-plausibility cells (weak single-family support);
- Pl vs naive mean: Pearson 0.9754 (not the average); Pl vs the DS
  algebraic OR b1+b2−b1·b2: Pearson 0.9374 — the conflict normalization
  depresses Pl exactly in the disagreement zones, which is the
  disagreement-preserving signature;
- Pl-top-B and Bel-top-B agree on 97.2 % of the budget set (Jaccard 0.9718),
  so the ranking swap only moves ~1,000 cells;
- zero SHA collisions against 46 existing rasters.

## 3. H50-B — radiometric alteration anomaly × conflict corridors (first non-fusion probe)

The preregistered slate's second-ranked testable-with-local-data hypothesis.
The GeoDAWN airborne radiometric mirror (official USGS DOI 10.5066/P93LGLVQ)
was restored byte-identical from the GEMSDOE24 public mirror via GitHub API
(SHA-256 `c22420f7…` verified against the mirror's own metadata receipt),
stored at `data/source_mirrors/geodawn_rad_u8.tif` (4-band uint8 K/Th/U/TC,
competition grid, 99.98 % footprint coverage).

Preregistered construction (constants frozen before scoring):
corridor = H50 conflict K > 0.3 (591,997 cells = the documented 11.5 %);
high-K gate = K band ≥ its in-footprint median; anomaly = robust z of Th/K
over admissible cells, lowest Th/K ranks first (argillic alteration
signature); emission = top 37,654 of the 172,548 admissible cells.
Artifact `gemsdoe48-h50b-alteration-conflict-20261007-806a4ba4-zeros.tif`.

## 4. What this session's evidence says about raising the live score

1. Fusion-of-existing-surfaces has plateaued. Four DS decision variants on the
   same B2 x H36-1 rung30 parent pair (Bel-graded, Bel-budget, Pl-graded, Pl-budget) score
   0.0707–0.0872 on the SGMC proxy and 0.0076–0.0313 on the catalogue proxy,
   while the parents themselves score 0.0933–0.0955 (SGMC) and 0.0068–0.0476
   (catalogue): **no tested fusion of this pair beat the better parent on
   these proxies**.
2. On both proxies the single best local artifact remains H49 (0.0954 /
   0.1008), a budget-matched pignistic emission over slightly more cells.
3. The metric is recall-weighted (FN cost 0.8 vs FP cost 0.2) and
   budget-linear, so the path to >0.2778 live is a detector with higher
   credit density (more true structure per emitted pixel), not a better
   combination of existing detections — exactly the N1–N5 leads (1 m DEM
   detection, gravity–magnetic edge coherence, ComCat/drainage, radiometric
   asymmetry used as a *structural* transform rather than an alteration rank).
