## H48-1 preregistered implementation and validation gate

1. Use only the two SHA-256-pinned source surfaces above and a separately derived survey-footprint mask. Do not use the sample submission's values as labels.
2. Treat each source value `p_i` as an operational binary opinion over `{fault, not-fault}` and discount it by the same fixed `rho=0.5`: `m_i(F)=rho*p_i`, `m_i(not-F)=rho*(1-p_i)`, `m_i(Theta)=1-rho`. Because zero means “no emitted confidence” in a sparse map, interpreting it as counter-evidence is a material assumption; retain it in all reports.
3. Compute the canonical normalized Dempster combination wherever defined, the raw conjunctive conflict `K`, and the residual unassigned mass `m(Theta)`. Store `K` separately because canonical Dempster normalization redistributes conflict; do not describe `K` as mass retained by canonical Dempster. If `1-K=0`, fail closed rather than invent a normalized probability.
4. Write a one-band float32 `m(F)` candidate in `[0,1]`; write `m(Theta)` and `K` as separate diagnostic GeoTIFFs. Do not min–max stretch the mass; it already lies in `[0,1]` and stretching would change its meaning.
5. Compare the fusion, each input, and their arithmetic mean on four fixed spatial blocks using the official 300 m distance-weighted Tversky metric (`alpha=0.2`, `beta=0.8`). Freeze the block geometry before scoring. Report paired block results, prediction mass, and positive-cell counts.
6. **Slot gate:** a numerical improvement over each input on at least 3/4 blocks is necessary but not sufficient. No weekly slot is cleared unless a fold-independent rebuild of the source models is possible and the holdout does not reuse held-out label geometry. If that cannot be done with the official labels/data, mark the result conditional and do not claim validation or leaderboard improvement.
7. Preserve a pre-result record. The next file, `evidence/holdout_20261006.json`, will carry the measured diagnostics and any leakage limitation; it cannot alter this slate.
